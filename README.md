# Aaron Morris Jara — Portfolio

Personal portfolio site: **https://aaron367123.github.io**

A static site (HTML, CSS and vanilla JavaScript, no build step) with a case-study page for each project and two live demos that run in the browser:

- `index.html`: home page
- `projects/`: one case study per project
- `demos/mips-emulator/`: step-through MIPS assembler and CPU
- `demos/pet-monitor-live/`: real-time IoT dashboard running in demo mode

Project source code: [Aaron367123/PortfolioProjects](https://github.com/Aaron367123/PortfolioProjects)

## Run locally

The demos use ES modules, so serve the folder over HTTP rather than opening the files directly:

```
python -m http.server 8000
```

Then open http://localhost:8000.
